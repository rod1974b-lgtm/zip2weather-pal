## Application architecture
- Keep weather lookup client-side through Open-Meteo and cache only the latest forecast in browser storage, because the app is intentionally account-free and private.
- Keep offline support generated by vite-plugin-pwa and register it only through the preview-safe wrapper, because service workers must never control Lovable previews.
